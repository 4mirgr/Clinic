# Site logo used in patient documents

`logo.webp` is the site's existing owner-supplied day logo, copied without editing from `4mirgr/gerami-website`, `assets/identity/logo-day.webp`, cached commit `3c2a0be0a2e2cb8224d336e2e502393b7f9793bd`. That repository's `assets/identity/sources.json` identifies it as exported original supplied artwork. It is not the generated clinical-orbit artwork.

Print font files `../fonts/vazirmatn-print-regular.ttf` and `vazirmatn-print-semibold.ttf` were obtained from the official `rastikerdar/vazirmatn` release tag `v33.003`, `fonts/ttf/Vazirmatn-Regular.ttf` and `Vazirmatn-SemiBold.ttf`. They include Persian and Latin glyphs. The existing SIL OFL in `../fonts/OFL.txt` applies.
