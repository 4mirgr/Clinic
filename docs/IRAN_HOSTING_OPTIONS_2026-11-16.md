# گزینه‌های میزبانی ایرانی — ۱۶ نوامبر ۲۰۲۶

مالک پس از مانع کارت Render و Northflank، بررسی سرویس ایرانی رایگان یا کم‌هزینه را درخواست کرد. این درخواست اجازهٔ مقایسهٔ قیمت است؛ سقف بودجه و خرید، شارژ کیف پول، ارتقا یا فعال‌سازی صورتحساب هنوز تأیید نشده‌اند. اولویت قبلیِ بدون هزینه پابرجاست مگر خود مالک مسیر دیگری انتخاب کند.

## نتیجهٔ صفحات رسمی زنده

قیمت‌ها از صفحات خود فروشندگان با دریافت زنده در تاریخ بالا خوانده شدند؛ قیمت پیشنهادی پنل حساب، ظرفیت قابل سفارش، مالیات نهایی و موفقیت اجرای Clinic هنوز تأیید نشده‌اند. ارقام زیر **تومان** هستند، نه ریال. این جدول هزینهٔ میزبانی برنامه است، نه فاکتور کاملِ تأییدشدهٔ سامانه با ایمیل، پشتیبان و سرویس‌های اضافه.

| گزینه | قیمت منتشرشده | منابع/شرط | کاربرد قابل بررسی |
| --- | --- | --- | --- |
| رانفلر رایگان | صفر، حداکثر سه ماه | مجموع پروژه: ۳GB رم، ۳GB دیسک، دو Deployment، کلاستر ایران | فقط تست و توسعه؛ غیرپروداکشن، بدون بک‌آپ؛ پس از سه ماه حذف کامل و غیرقابل بازیابی |
| رانفلر Docker کوچک | ۳۲۰٬۰۰۰ در ماه؛ ساعتی ۴۴۴ | ۵۱۲MB رم، ۵۰۰MB دیسک، دو Deployment؛ صفحه DE/IR را نشان می‌دهد | نامزد کم‌هزینه با Docker فعلی؛ ظرفیت/مصرف واقعی و مبلغ نهایی نیازمند بررسی |
| رانفلر Docker یک‌گیگابایتی | ۴۴۰٬۰۰۰ در ماه؛ ساعتی ۶۱۱ | ۱GB رم، ۲GB دیسک، دو Deployment؛ DE/IR | نامزد پیشنهادی در صورت امکان این بودجه؛ اجرای واقعی هنوز آزموده نشده |
| چابکان Docker «پایه» | ۶۳۰٬۹۹۰ برای ۳۰ روز | ۰٫۵GB رم، ۰٫۵ هسته، ۵GB فضا | قیمت پیش از مالیات و گزینه‌های اختیاری؛ از نامزد رانفلر گران‌تر است |
| لیارا PaaS «زمین» | ۷۵۰٬۰۰۰ در ماه؛ ساعتی ۱٬۰۴۱ | ۰٫۵۱۲GB رم، ۰٫۵ vCPU، ۵GB دیسک | Docker و Django مستند دارند؛ مبلغ نهایی/سطح پشتیبانی در پنل باید روشن شود |

ارقام منابع رانفلر، پلن **پروژه** هستند؛ نباید برای هر Deployment دوباره تمام منابع جدول را فرض کرد. صفحهٔ Docker از نام‌گذاری Ghz برای CPU استفاده می‌کند؛ آن را به vCPU یا هستهٔ تضمین‌شده تبدیل نکردیم. منابع عملی و بودجهٔ کانتینر هر برنامه باید در پنل بررسی شوند.

**رایگان دائمیِ تأییدشده برای پرونده‌های واقعی پیدا نشد.** رانفلر صریحاً عدم بک‌آپ، غیرپروداکشن‌بودن و حذف سه‌ماهه را اعلام کرده است. اجازهٔ ایجاد سرویس رایگان جدید پس از پایان را با ماندگاری یا تمدید خودکار سرویس فعلی یکی نگیرید؛ انتقال پی‌درپی/چرخش حساب یا اتکا به آن برای دادهٔ بیمار پیشنهاد نمی‌شود. ۵۰هزار تومان هدیهٔ شروع نیز تخفیف/اعتبار اولیه است، نه میزبانی رایگان دائمی.

چابکان پلن‌های Docker ارزان‌تر با ۱۵۰MB و ۲۵۰MB رم هم نشان می‌دهد؛ آن‌ها بدون آزمون مصرف برای Django/Gunicorn فعلی پیشنهاد نمی‌شوند. قیمت‌های پایین‌ترِ صفحات Python را با Docker مخلوط نکردیم: بازیابی زندهٔ قیمت صفحهٔ Python رانفلر پاسخ قیمت قابل اتکا نداد، درحالی‌که صفحهٔ Docker ارقام بالا را صریح نشان داد. قیمت جست‌وجو/صفحهٔ پلتفرم دیگر مبنای فاکتور نیست.

دو گزینهٔ دیگر بررسی شدند: هاست رایگان server.ir پشتیبانی Python/PostgreSQL، سقف اشتراکی رم ۱GB و نبود SSH را اعلام می‌کند، اما نسخهٔ Python 3.12، استقرار Docker و اتصال خارجی به Neon را ثابت نمی‌کند و برای آزمایش معرفی شده؛ فعلاً برای همین کد توصیه نشده است. هم‌روش قیمت واحد CPU/RAM/دیسک/ترافیک را جدا می‌گیرد؛ بدون حداقل تخصیص قابل سفارش، جمع فرضی را به‌عنوان قیمت نهایی ماهانه معرفی نکردیم.

## سازگاری و گام بعدی

- مستندات رسمی رانفلر ساخت از Dockerfile، اتصال GitHub با انتخاب مخزن/branch، ترمینال و SSL را نشان می‌دهند. این شواهد امکان فنی اولیه‌اند، نه تأیید حساب/میزبان. هیچ حساب، سرویس، مجوز GitHub، کیف پول یا صورتحساب از طرف عامل ایجاد یا تغییر نکرده است.
- اگر مالک مسیر تستِ بدون هزینه را انتخاب کند، نخست باید فعال‌بودن واقعی همان پلن سه‌ماهه و نبود پرداخت اجباری در حسابش مشخص شود؛ فقط پیش‌نمایش و دادهٔ ساختگی. در صورت نیاز به شارژ/کارت یا نبود منابع، توقف؛ ایجاد خودکار پلن پولی مجاز نیست.
- اگر مسیر پولی انتخاب شود، اول بودجه، مبلغ نهایی شامل مالیات و گزینه‌های اجباری، دورهٔ پرداخت، موجودی واقعی پلن و نبود ارتقای خودکار در پنل روشن شود؛ هنوز اجازهٔ پرداخت صادر نشده است. پلن یک‌گیگابایتی نامزد است، نه ادعای ظرفیت اندازه‌گیری‌شده یا آمادگی تولید.
- پیش از خرید/اتصال نهایی، خروج TCP/TLS به endpoint واقعی Neon و ورود HTTPS از Cloudflare باید از خود میزبان تأیید شوند؛ مدارک قیمت این مسیر شبکه را ثابت نمی‌کنند. از محدودیت شبکه با پروکسی پنهان یا بانک بیمار مستقل عبور نکنید.
- همان Docker/Gunicorn روی پورت ۸۰۰۰، بانک اختصاصی Neon با TLS، `CLINIC_DOCUMENT_STORAGE=database`، secrets جداگانهٔ Preview/Production و هویت Django مبنا هستند. بانک/مدارک به MySQL، D1، هاست آزمایشی یا پروژهٔ IntMed/AUS منتقل نمی‌شوند.
- PR7 تا مهاجرت کامل، TLS/کلیدهای جفت، فایل خصوصی، پشتیبان مستقل و بازیابی، smoke واقعی حساب مشترک و پاک‌سازی فقط دادهٔ ساختگی مسدود می‌ماند. این تحقیق به معنی انتشار یا تست محصول جدید نیست.
